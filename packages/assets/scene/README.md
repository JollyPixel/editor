## 💃 Getting Started

This workspace-private package will store `.scene.json` scenes: a tree of actors, each with an ordered list of components that can reference other assets. Add `"@jolly-pixel/asset.scene": "workspace:*"` to another workspace's dependencies.

🚧 Not built yet. The design lives in `packages/editors/scene/SPEC.md`.

## ✨ Contributors guide

Read the [contributing guide](../../../CONTRIBUTING.md) before submitting a change. Run `pnpm --filter @jolly-pixel/asset.scene test` and `pnpm run lint` from the monorepo root.
