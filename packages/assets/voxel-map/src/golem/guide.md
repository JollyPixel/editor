A `voxelmap` is a grid of cells in layers. Each cell holds a block from one of the map's blocksets. A new map comes with an empty `default` blockset and no layer.

- Start with the map's `summary` intent: layers with their bounds, blocksets and the blocks you can place. Positions are whole cells, y is up, and a box `{ min, max }` includes both corners.
- Define blocks on a blockset with `asset_apply` on the blockset asset: `{ "action": "block-defined", "block": { "id": 1, "name": "stone", "shapeId": "cube", "faceTextures": { "top": [1, 0] }, "defaultTexture": [0, 0], "collidable": true, "properties": {} } }`. Ids are local to the blockset.
- A blockset's texture is a grid of square tiles, `tileSize` pixels wide (`asset_read` on the blockset). A tile `[col, row]` covers x `col * tileSize`, y `row * tileSize`. `faceTextures` names a tile per face slot (`right`, `left`, `top`, `bottom`, `front`, `back`); the other faces use `defaultTexture`. Paint the tiles with the blockset's `readPixels`, `paint`, `fillRect` and `replacePalette` intents.
- Other block fields: `collidable` (default true), `alphaMode` (`opaque`, `mask` or `blend`), `alphaCutoff` (0 to 1, for `mask`), `side` (`front` or `double`), `cullCoveredFaces`, `blendGroup` (the group whose rules fade its top and bottom into neighbours), `materialGroup` and free-form `properties`.
- Light comes from a material group, not from the block: define one with `{ "action": "material-group-defined", "group": { "id": "lava", "emissive": "#ff6600", "emissiveIntensity": 2, "lightLevel": 12 } }` (`roughness` and `metalness` 0 to 1, `normalScale`, `lightLevel` 0 to 15), then set the block's `materialGroup` to `"lava"`.
- Add a layer with the map's `addLayer` intent, on top or `above` another. Use the name or id it returns: a taken name gets a number appended.
- `fillBox` and `clearBox` write a box on one layer. Name blocks as `summary` lists them; use `"<blockset>/<name>"` when two blocksets share a name.
- Check the result with `heightmap` (the top of each column) or `query` (cells of a small box). You cannot see the map.
- For terrain, caves or anything shaped by a formula, write a script: `golem.open(assetId, "voxelmap")` returns a `VoxelMapAsset` with `fillBox`, `clearBox` and `writeVoxels`. `skill/examples/voxelMapTerrain.ts` in the golem package raises a terrain from a height formula. `golem.open(assetId, "blockset")` returns a `BlocksetAsset` whose `pixels` paints its texture.
