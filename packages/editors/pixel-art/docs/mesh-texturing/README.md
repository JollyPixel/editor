# Mesh texturing

Three.js adapters from `@jolly-pixel/editor.pixel-art/mesh-texturing`:

- [`PixelCanvasTexture`](./PixelCanvasTexture.md) mirrors a canvas and its
  normal map into GPU textures.
- [`UVGeometryBinding`](./UVGeometryBinding.md) projects UV regions onto mesh UVs.
- [`clampUvRegion`](./clampUvRegion.md) keeps sampling inside each face's region.
- [`NormalMapTexture`](./NormalMapTexture.md) wraps a `NormalMap` as a data
  texture.
