# Voxel Map confirmed bugs

1. Right now we cannot add a new block in front of a ramp shape (it's impossible). Ideally what we should always do whatever the shape is to compute the block bounding box (like a cube shape) and place the block on the neighbour face where our mouse cursor is. Right now I think we are doing a lot of weird Math but this may introduce this kind of weird behavior.
2. While using the drag painting there is a missing constraint which consist to wait for the cursor to be move into a nother block before allowing to place a new block (or remove it). Right now we have a delay constraint which is good but we need to add this constraint in addition. Without that, when we stay clicked without moving the cursor, block appear at the location of the cursor but also in the neighbour face (which is not expected). If I stay at the same location while the click is down, the block should not appear in the neighbour face.
3. Not a real bug but right now we can only place a block using the plane (which is visually represented by the Grid). But if we want to create block more freely like an island in the sky we can't do that. The idea would be to add a Sphere plane around the camera with a parametrable radius. We would keep the Grid plane for the ground but add a Sphere plane for the sky. Then like that we could be able to place blocks more freely in the sky while keeping current behavior while working on the ground.
