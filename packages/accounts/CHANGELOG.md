# @jolly-pixel/accounts

## 2.0.0

### Major Changes

- [#1247](https://github.com/JollyPixel/editor/pull/1247) [`042847c`](https://github.com/JollyPixel/editor/commit/042847c4f6607dcd7785e3f3fedd5fef5f373c52) Thanks [@fraxken](https://github.com/fraxken)! - Split server-wide accounts from per-project membership (`accounts.realm()`); roles, access requests, share links and agent tokens belong to a realm.

### Minor Changes

- [#1231](https://github.com/JollyPixel/editor/pull/1231) [`40b7a52`](https://github.com/JollyPixel/editor/commit/40b7a52eb6d394cfb4959aeb07abe807fb599bb0) Thanks [@fraxken](https://github.com/fraxken)! - Add agent tokens (`accounts.agentTokens`) to connect a local AI agent with its owner's current role, and `isAgentProfile(profile)` to recognize one.
  Revoking the token or changing the owner's role revokes the agent's connections.

- [#1247](https://github.com/JollyPixel/editor/pull/1247) [`6f83ad9`](https://github.com/JollyPixel/editor/commit/6f83ad96f79668f426e90a6f7e183d6f676778ea) Thanks [@fraxken](https://github.com/fraxken)! - Sign-in is server-wide, and accounts join realms with `AccountsRealm.join`. Admins can invite members and the owner can delete accounts.

- [#1240](https://github.com/JollyPixel/editor/pull/1240) [`69ba6ea`](https://github.com/JollyPixel/editor/commit/69ba6ea57e3d74350f44c1b36e361c6c01ad2f8f) Thanks [@fraxken](https://github.com/fraxken)! - Add `server.disconnect(subject)` to close a subject's connections, which agent tokens use to drop an agent while keeping its token.

### Patch Changes

## 1.1.0

### Minor Changes

- [#943](https://github.com/JollyPixel/editor/pull/943) [`c28ae6b`](https://github.com/JollyPixel/editor/commit/c28ae6be469f6c67136d3106f73202656c4fe435) Thanks [@fraxken](https://github.com/fraxken)! - Add a `masterPassword` for the first registration and admin-approved access requests. The host now serves the HTTP routes (`ACCOUNTS_ROUTES`), and domain errors extend `AccountsError`.

- [#945](https://github.com/JollyPixel/editor/pull/945) [`c0643f9`](https://github.com/JollyPixel/editor/commit/c0643f9978941d93eb2fee7ca4d524fc20e23339) Thanks [@fraxken](https://github.com/fraxken)! - The first account owns the server and can transfer ownership. `new Accounts()` takes `{ database, roles }`, with `AccountsDatabase` replacing `AccountStore`.

- [#1073](https://github.com/JollyPixel/editor/pull/1073) [`8bd8a3f`](https://github.com/JollyPixel/editor/commit/8bd8a3f04ba38872f9db95a83fdbdbb779b72800) Thanks [@fraxken](https://github.com/fraxken)! - `Accounts.replaceRoles(roles, renamed)` moves the accounts and access requests of each renamed role to its new name and revokes them.

- [#945](https://github.com/JollyPixel/editor/pull/945) [`ef2c7fe`](https://github.com/JollyPixel/editor/commit/ef2c7fe37e1d532b745e6462c26bb9f650ccc875) Thanks [@fraxken](https://github.com/fraxken)! - Profiles and avatars update live for every room member, without reconnecting.

- [#963](https://github.com/JollyPixel/editor/pull/963) [`f20007a`](https://github.com/JollyPixel/editor/commit/f20007a1717a9b9bbab779489156c36451be38a0) Thanks [@fraxken](https://github.com/fraxken)! - Add view-only share links: guests see a read-only catalog limited to one asset and what it depends on.

- [#1045](https://github.com/JollyPixel/editor/pull/1045) [`695ee81`](https://github.com/JollyPixel/editor/commit/695ee81072bd90cae25c03e5e850ce214153278b) Thanks [@fraxken](https://github.com/fraxken)! - Rights, roles, kind options and access requests can change without a restart. Accounts store per-account `preferences`. `OrbitFlyCamera` gains `invertY` and touchpad swipe modes.

### Patch Changes

- [#1025](https://github.com/JollyPixel/editor/pull/1025) [`3d53ea9`](https://github.com/JollyPixel/editor/commit/3d53ea9ae1d62eed99cde3dd80a1c8831deedffb) Thanks [@fraxken](https://github.com/fraxken)! - Transports decode the credential into `request.credential` and refuse a malformed one; `readCredential` and `InvalidCredentialError` are removed.
