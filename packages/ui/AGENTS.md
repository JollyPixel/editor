## Architecture decisions

Read `docs/adr/README.md` before changing state ownership, theming, collaboration, input scope,
persistence, event shapes or package boundaries. Add a record only when a decision is hard to reverse
and surprising without context. A choice confined to one component's API goes in its API page
instead. Extend an existing record by editing it; write a new record only to reverse one, and mark
the old one superseded.
