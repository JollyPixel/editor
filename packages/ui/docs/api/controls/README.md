# Controls API

Field controls share the [field API](../field/shared-field-api.md). Each page
below documents the properties and behavior owned by one component.

- [`jolly-button`](./button.md), exported as `Button`
- [`jolly-button-group`](./button-group.md), exported as `ButtonGroup`
- [`jolly-checkbox`](./checkbox.md), exported as `Checkbox`
- [`jolly-color`](./color.md), exported as `Color`
- [`jolly-color-picker`](./color-picker.md), exported as `ColorPicker`
- [`jolly-control`](./control.md), exported as `Control`
- [`jolly-controls`](./controls.md), exported as `Controls`
- [`jolly-flags`](./flags.md), exported as `Flags`
- [`jolly-number`](./number.md), exported as `NumberField`
- [`jolly-property-row`](./property-row.md), exported as `PropertyRow`
- [`jolly-range`](./range.md), exported as `Range`
- [`jolly-select`](./select.md), exported as `Select`
- [`jolly-separator`](./separator.md), exported as `Separator`
- [`jolly-slider`](./slider.md), exported as `Slider`
- [`jolly-text`](./text.md), exported as `Text`

See [Choosing controls](../../guides/choosing-controls.md) for a value-to-control
map.
