## 💃 Getting Started

This workspace-private package holds the headless terrain data: chunk
coordinates, chunks of 64×64 owned samples, and the `TerrainDocument` with
world-space sampling. The CDLOD view, the TSL materials and the engine plugin
come next; see the terrain editor [design][design] and [roadmap][roadmap].
