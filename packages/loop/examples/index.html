Frame inspector Live plot of every decision the scheduler makes. F3 toggles the panel.

Three lanes, oldest frame on the left: frame delta (time the frame took), steps per frame (fixed updates it ran, with the step budget dashed), accumulator (simulation time owed, always under one fixed delta). Each lane prints the value its top edge stands for — it auto-scales, so read it before comparing two plots. A vertical dashed line marks the frame where a setting changed.

Healthy: steady blue bars, steps alternating between the same one or two values, a sawtooth accumulator. Raise fixedFps above your display rate to see steps double up; cap maxFps below it to see frames stop being drawn while the simulation keeps stepping.
